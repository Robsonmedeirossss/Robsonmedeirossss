## 💻 Sobre mim

Sou desenvolvedor backend Java, graduado em Engenharia de Software pela Universidade Federal do Ceará (UFC). Atualmente, trabalho com desenvolvimento e manutenção de aplicações backend utilizando Java e Spring Boot.

Tenho interesse especial em arquitetura backend, integração entre sistemas, segurança de aplicações, bancos de dados e computação em nuvem. Busco desenvolver soluções confiáveis e de fácil manutenção, aplicando boas práticas de engenharia de software.

## 🛠️ Stack e áreas de atuação

* **Backend:** Java, Spring Boot, Spring Security e Hibernate.
* **Banco de dados:** PostgreSQL, SQL e Flyway.
* **Segurança:** autenticação, autorização e integração com Keycloak.
* **Infraestrutura:** Docker e configuração de ambientes com Dockerfile, Docker compose.
* **Cloud:** AWS, com experiência prática em S3, SQS, SNS, SES etc.
* **Ferramentas:** Git, GitLab, GitHub, Maven, Swagger.

## 🚀 Interesses técnicos

Atualmente, direciono meus estudos e projetos para o aprofundamento em arquitetura de aplicações backend, integrações com serviços externos, processamento assíncrono, mensageria e infraestrutura em nuvem.

Busco ampliar minha experiência com serviços AWS e sistemas distribuídos, aplicando esses conhecimentos em projetos práticos com Java e Spring Boot.

## 🎓 Formação e experiência

* **Engenharia de Software — Universidade Federal do Ceará (UFC)**, Campus Russas.
* Experiência profissional anterior em Quality Assurance, Treinamento e Desenvolvimento e Engenharia de Prompts, com atuação em qualidade de software, plataformas digitais e automações com inteligência artificial.
